تحديث الطالب الصامد Android Offline 1.3
=====================================

سبب الصور المرفقة:
1) فشل سلامة الوحدة: التطبيق كان يتوقع ZIP محدثًا، بينما GitHub أعاد ZIP قديمًا بالاسم نفسه.
2) تعارض الحزمة: النسخة القديمة وAPK الجديد موقّعان بمفتاحي Debug مختلفين.

خطوات الرفع الصحيحة:
1. ارفع جميع محتويات هذه الحزمة إلى GitHub.
2. تأكد خصوصًا من ظهور الملفين بالاسم الجديد:
   unit_packs/physics12_unit1_offline_v3.zip
   unit_packs/chemistry12_unit1_offline_v3.zip
3. افتح كل ملف على GitHub وتأكد أنه موجود قبل بناء APK.
4. شغّل Actions > Build Android APK and AAB > Run workflow.
5. حمّل student-samed-apk وثبّت app-debug.apk.

مهم عند تثبيت 1.3:
- احذف نسخة التطبيق القديمة مرة واحدة فقط، لأنها تحمل توقيعًا مختلفًا.
- ثبّت APK 1.3 الجديد.
- من هذا الإصدار يوجد debug.keystore ثابت داخل مشروع الاختبار؛ لذلك ستُثبت التحديثات التالية فوق 1.3 دون تعارض، ما دام الملف app/debug.keystore لا يُحذف أو يُستبدل.

ملاحظة أمنية:
- debug.keystore خاص بالاختبار والتوزيع المباشر خارج المتجر.
- لا تستخدمه لتوقيع نسخة Google Play. أنشئ مفتاح Release خاصًا واحفظه سرًا عند نشر AAB.
